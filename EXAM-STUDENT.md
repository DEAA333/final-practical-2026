# Laravel 13 Practical Exam — Student Brief

## Scenario
Complete a Maintenance Management System using Laravel 13, Blade, Eloquent, migrations, validation, authorization.

## 15 Practical Tasks
1. Run, migrate and seed the project successfully.
2. Verify and fix Models and all Eloquent relationships.
3. Complete the request listing with customer/technician data.
4. Implement search by title/customer and filters by status, priority and technician.
5. Add pagination and preserve filters.
6. Complete request creation.
7. Add complete server-side validation and Blade error feedback.
8. Complete edit/update and old-value handling.
9. Enforce authorization: technicians can only modify their assigned requests; admins have full control.
10. Complete the request details page and actions.
11. Implement rating rules: completed requests only, correct customer only, one rating per request.
12. Find and fix all intentional bugs without removing required functionality.
13. Identify and remove an N+1 query risk; explain your eager loading.
14. Complete the individualized surprise task assigned by the instructor.

## Submission
Push to the assigned GitHub repository. Do not commit `.env`, `vendor/`, or `node_modules/`.

Add `STUDENT-NOTES.md` with completed tasks, assumptions, limitations, AI tools used if allowed, and two changes you made after testing.

You must be able to explain your code and perform a small live modification.

# Laravel Practical Exam

## Scenario

You are developing a Maintenance Management System for a technical service center.

The system manages:
- Customers
- Technicians
- Maintenance Requests
- Ratings

## 15 tasks

1. Run the project and database successfully.
2. Fix and verify all model relationships.
3. Display maintenance requests with customer and technician information.
4. Add search by customer name/title and filters by status, priority and technician.
5. Add pagination while preserving filters.
6. Complete the create-request workflow.
7. Implement robust validation and display validation errors.
8. Complete request editing.
9. Implement authorization: technicians may only modify their assigned requests; admins have full control.
10. Build a complete request details page.
11. Implement customer rating for completed requests and prevent duplicate ratings.
12. Find and fix the intentional debugging issues.
13. Implement the required requests API.
14. Improve Eloquent usage and remove an N+1 query problem.
15. Complete the surprise requirement supplied by the instructor.

## Submission

Submit the project without:
- vendor/
- node_modules/
- .env

Include a short README describing:
- installation
- test accounts
- completed tasks
- any known limitations

## Oral check

The instructor may ask you to explain or modify any part of your code.
